# MIXCALL LAB — HEROINES 믹스콜 연습 사이트

빌드 없이 동작하는 정적 사이트입니다. `python3 -m http.server` 등으로 `mixcall-web/`을 열면 됩니다.

## 구성
| 메뉴 | 내용 |
|---|---|
| 곡별 | 노션에 콜이 정리된 HEROINES 13곡. 곡을 열면 콜이 원형 노드로 이어지는 플로우(Make 시나리오 편집 화면 레이아웃) |
| MIX | MIX 라이브러리 33종 — 계열별 모듈, 전문(일본어 + 한국어 발음), 쓰이는 곡, 단독 연습 |
| 분류 | 계열 × 속도 × 치는 방식 3축 필터로 MIX와 곡 속 콜 찾기 |
| AI 음성 | MIX별 클론 음성 클립 등록(IndexedDB), 최애 이름, 일본어 TTS 설정 |
| 가이드 | 사용법, 표기 규칙, 분류 축 설명 |

## 실행 방식
- **▶ 실행**: 선택한 노드부터 차례로 재생. 노드 패널에 콜 전문이 줄 단위로 강조됩니다.
- **YouTube 구간**: 각 콜의 시작~끝 구간만 재생(음원 전체를 쓰지 않음). 구간이 없는 콜은 데모 비트로 대신 재생.
- **● 기록**: 영상을 재생하며 [Space]로 콜 시작·끝을 찍어 구간 저장(브라우저 localStorage). ⚙에서 JSON 백업·가져오기.
- **AI 음성**: 노드(곡별) 또는 MIX별 클론 음성 클립 → 없으면 일본어 TTS. 배포용 클립은 `voices/<키>.mp3` + `voices/voices.json` (키: MIX id 또는 `song:<곡id>:<노드번호>`).

## 데이터
- `data/mixes.js`, `data/songs.js` — 노션 「히로인즈 콜 — 가사·믹스콜 자료」, 「MIX 전문집」(2026-10-12) 기준.
- 가사 전문은 넣지 않고 콜 직전 가사 한 줄 앞부분만 큐로 둡니다. 멤버 이름은 ○○.
- 발음 규칙: 장음은 모음 반복, ファ·フィ·フェ=화·휘·훼, ツ=츠, 촉음=받침 ㅅ.
