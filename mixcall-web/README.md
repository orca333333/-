# MIXCALL LAB — 지하아이돌 믹스콜 학습 사이트

빌드 없이 동작하는 정적 웹사이트입니다. `index.html`을 정적 서버로 열면 됩니다.

```bash
cd mixcall-web
python3 -m http.server 8000   # → http://localhost:8000
```

## 기능

| 메뉴 | 내용 |
|---|---|
| 곡별 | 곡 검색 → 플레이어(음원 + 가사·콜 타임라인 + AI 음성) |
| 믹스콜별 | 종류·속도·방식(언어계)·위치·자료 신뢰도 필터, 단어별 박 배치·한국어 발음, 단독 반복 연습(BPM 조절) |
| 성격별 | 정형·열광·고백·고속·클랩·매너 주의 6분류, 해당 콜이 들어간 곡 연결 |
| AI 음성 | 콜별 AI 클론 음성 클립 업로드(IndexedDB), 최애 이름 설정, 미등록 콜은 일본어 TTS로 대체 |
| 곡 추가 | YouTube 링크·BPM·`소절.박 | 종류 | 내용` 타임라인으로 실제 곡 등록, JSON 내보내기/가져오기 |

### 음원
- **데모 비트**: Web Audio로 BPM에 맞춘 킥·클랩·하이햇 생성(4박 카운트인).
- **YouTube 임베드**: `enablejsapi` iframe을 postMessage로 제어. 곡마다 *싱크 오프셋(초)* 을 맞춰야 콜이 박에 붙습니다.
- 저작권 문제로 실제 곡 음원·가사는 포함하지 않습니다. 데모곡 가사는 연습용 창작 문장입니다.

### 나의 AI 음성 (클론) 적용
1. 보이스 클로닝으로 각 콜 구호(일본어)를 생성 → 앞뒤 무음 제거
2. 개인용: **AI 음성** 메뉴에서 콜별 업로드(브라우저에만 저장)
3. 배포용: `voices/<콜ID>.mp3`로 넣고 `voices/voices.json`에 ID 목록 기입. 예: `["standard","japanese"]`

콜 ID: `standard` `japanese` `ainu` `encho` `kahen3` `ietiger` `ppph` `uryaoi` `gachikoi` `namecall` `kecak`

## 데이터 (`data.js`)
- 박 배치는 4/4박 기준 **일반적 예시**이며 곡·현장마다 다릅니다.
- `confidence`: `cross`(복수 팬 자료 교차 확인) / `single`(단일 출처) / `unverified`(일반 지식, 확인 필요)
- 원장 MIX·가변 삼연 MIX는 전체 구호를 확인하지 못해 확인된 부분만 넣고 나머지는 `［確認必要］`로 표시했습니다.
