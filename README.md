# ChatBridge (스마트폰 내역 통합 앱)

스마트폰의 여러 내역을 하나의 앱에서 확인/응답하는 것을 목표로 하는 안드로이드 앱입니다.
현재 5개 메뉴가 모두 구현되어 있습니다: **1. 카카오톡 · 2. 유튜브 · 3. 뉴스 · 4. SNS · 5. 뱅크샐러드(가계부)**.

## 왜 이렇게 만들었는가 (공통 제약)

카카오톡·뱅크샐러드·X·인스타그램·틱톡 모두 "개인 데이터를 읽거나 대신 조작할 수 있는" 공식 API를 제공하지
않습니다. 그래서 메뉴 1, 4, 5는 안드로이드 시스템 기능 두 가지로 각 앱의 화면을 직접 읽거나 조작합니다.

1. **알림 접근 권한 (`NotificationListenerService`)**: 카카오톡 알림(발신자/채팅방 이름, 메시지 미리보기)을 읽습니다.
2. **접근성 권한 (`AccessibilityService`, `BridgeAccessibilityService`)**: 카카오톡 답장 전송, 뱅크샐러드
   가계부 화면 읽기, X/인스타그램/틱톡 프로필 화면 읽기를 위해 해당 앱의 실제 UI를 열고 텍스트를 넣거나 화면의
   텍스트를 수집합니다. 각 앱의 화면 구성이 바뀌면 깨질 수 있는 **본질적으로 휴리스틱한 방식**입니다.

이 방식 때문에:

- **안드로이드 전용**입니다. iOS는 이런 방식의 알림 가로채기/자동 조작이 기술적으로 불가능합니다.
- 구글 플레이 정식 심사에서는 반려될 가능성이 높아 **APK 사이드로드(직접 설치) 전용**으로 설계했습니다.
- **X/인스타그램/틱톡은 자동화 탐지가 적극적이라, 본인 계정이 일시정지/제한될 위험이 실질적으로 있습니다.**
  이 위험을 감수하고 진행하기로 결정한 기능입니다.
- 채팅·가계부·SNS 데이터는 **기기 내부(Room/SQLite)에만 저장**됩니다. 다만 메뉴 2(유튜브 API), 3(뉴스
  RSS), 3·5(Claude API 요약)는 인터넷 통신이 필요합니다 — 더 이상 "완전 오프라인" 앱은 아닙니다.

## 메뉴별 설명

### 1. 카카오톡
- 내가 "요청(선택)"한 사람/채팅방(오픈채팅 포함)만 앱에서 확인·답장할 수 있습니다.
- 선택하지 않은 채팅방은 이름만 "채팅방 선택" 화면에 나타날 뿐 메시지 내용은 저장되지 않습니다.
- 채팅방은 카카오톡 API로 목록을 가져올 수 없어 **알림에 찍힌 이름으로만 식별**합니다.

### 2. 유튜브
- 채널을 검색해서 추가하면, 해당 채널의 최신 업로드 영상이 피드에 표시됩니다.
- 영상을 탭하면 유튜브 앱(없으면 브라우저)에서 재생됩니다 — 재생 자체는 항상 공식 유튜브를 통해 이뤄집니다.
- **YouTube Data API v3 키**가 필요합니다(설정 화면에서 입력). [Google Cloud Console](https://console.cloud.google.com/)에서
  무료로 발급받을 수 있으며, 일일 쿼터 제한이 있습니다.

### 3. 뉴스
- 정치·경제·전쟁·연예·과학·스포츠·날씨 7개 카테고리를, **구글 뉴스 RSS(한국판)**를 통해 당일 08:00까지
  발행된 기사 기준으로 모읍니다.
- 제목은 Claude API 키가 설정된 경우 자동으로 간결하게 재작성되고, 키가 없으면 원문 제목이 그대로 표시됩니다.
- 카테고리별 탭에서 제목만 보이는 리스트를 아래로 스크롤하며 볼 수 있고, 탭하면 실제 기사 링크로 이동합니다.
- 매일 08:05경 백그라운드에서 자동 갱신되며, 화면에서 수동 새로고침도 가능합니다.
- 특정 언론사 RSS 대신 구글 뉴스를 쓴 이유: 개별 언론사 RSS 주소는 검증 없이 넣으면 깨질 위험이 커서,
  안정적으로 검증 가능한 방식을 택했습니다. `data/news/NewsSources.kt`에서 언제든 특정 언론사 피드로 바꿀 수 있습니다.

### 4. SNS (X / 인스타그램 / 틱톡)
- 플랫폼과 계정 핸들을 등록하면, 접근성 서비스가 해당 계정의 프로필 화면을 열어 최근 게시물 텍스트를 읽어옵니다.
- **중요한 한계**: 이 방식으로는 게시물 하나하나의 실제 링크(퍼머링크)를 알아낼 수 없습니다. 화면에 URL이
  텍스트로 표시되지 않기 때문입니다. 그래서 카드를 탭하면 해당 게시물이 아닌 **계정 프로필 페이지**로 이동합니다.
- 자동화 탐지 위험이 카카오톡보다 훨씬 큽니다 — 사용 전 README 상단의 위험 고지를 꼭 읽어주세요.

### 5. 뱅크샐러드 (가계부)
- 화면의 "지금 갱신" 버튼을 누르면 뱅크샐러드 앱이 열리고, 접근성 서비스가 가계부 화면의 텍스트를 읽어
  스냅샷으로 저장합니다.
- Claude API 키가 설정되어 있으면 그 텍스트를 바탕으로 3~5줄짜리 재정 상태 요약을 자동 생성합니다. 키가
  없으면 원문 텍스트 일부가 그대로 표시됩니다.
- **하루 한 번 자동 갱신은 안드로이드가 백그라운드에서 다른 앱을 몰래 여는 것을 막기 때문에 완전 자동은
  아닙니다.** 매일 알림이 오고, 그 알림을 탭해야 실제 갱신이 시작됩니다.
- 재무 데이터라 민감도가 가장 높습니다 — 스크랩 결과는 기기 밖으로 나가지 않지만(Claude 요약 시 텍스트가
  Anthropic API로 전송되는 것은 예외), 화면에 떠 있는 다른 정보까지 함께 읽힐 수 있다는 점을 감안하세요.

## 처음 사용 설정

1. 앱 설치 후, 카카오톡 화면 상단 배너의 안내를 따라 다음 두 권한을 켭니다.
   - **알림 접근 권한** (설정 > 앱 > 특별한 접근 > 알림 접근)
   - **손쉬운 사용(접근성) 권한** (설정 > 접근성 > ChatBridge)
2. 알림 권한도 최초 실행 시 요청됩니다(뱅크샐러드/SNS 일일 알림용, Android 13+).
3. 메뉴 2(유튜브)·3(뉴스 요약)·5(가계부 요약)를 쓰려면 각 화면의 설정(⚙) 아이콘에서 API 키를 입력하세요.
   - YouTube Data API 키: 메뉴 2에 필수
   - Claude API 키: 메뉴 3/5의 AI 요약에 필요 (없어도 원문은 표시됨)
4. 카카오톡은 메시지가 한 번 이상 와야 "채팅방 선택" 화면에 목록이 뜹니다. SNS도 마찬가지로 계정을
   등록하고 새로고침해야 게시물이 쌓입니다.

## 빌드 방법

Android Studio(최신 버전)에서 이 폴더를 열면 Gradle Wrapper가 자동 생성됩니다.
CLI로 빌드하려면 로컬에 Gradle이 설치되어 있어야 하며(`gradle wrapper` 최초 1회 실행 후):

```
./gradlew assembleDebug
```

- `minSdk` 26, `targetSdk` 34, Kotlin + Jetpack Compose + Room + WorkManager + OkHttp 사용.
- API 키는 사용자가 설정 화면에서 직접 입력하며 `EncryptedSharedPreferences`로 기기에만 암호화 저장됩니다.
  소스코드에는 어떤 키도 포함되어 있지 않습니다.

## 프로젝트 구조

```
app/src/main/java/com/chatbridge/kakao/
  data/
    ChatDao/ChatRepository 등        메뉴 1(카카오톡) 로컬 저장
    youtube/                         메뉴 2: YouTube Data API 클라이언트 + 로컬 캐시
    news/                            메뉴 3: RSS 소스, 파서, 일일 다이제스트 저장
    sns/                             메뉴 4: 등록 계정, 스크랩된 게시글 미리보기
    finance/                         메뉴 5: 뱅크샐러드 스냅샷 + AI 요약
    scrape/                          메뉴 4/5 공용 "화면 읽기 작업" 큐
    ai/ClaudeSummarizer.kt           Claude API 호출 (제목 요약, 재정 요약)
  notification/  KakaoNotificationListenerService   (메뉴 1: 메시지 읽기)
  accessibility/ BridgeAccessibilityService          (메뉴 1/4/5: 답장 전송·화면 스크랩)
  work/          NewsRefreshWorker, DailyReminderWorker, Schedulers  (일일 자동 갱신)
  ui/screens/    5개 메뉴 화면 + 설정 화면
  ui/common/     메뉴 3/4가 공유하는 "제목만 보이는 스와이프 리스트" 컴포넌트
  MainActivity.kt  하단 메뉴 5개 + 알림 딥링크 처리 + 네비게이션
```

## 알려진 한계

- **메뉴 1**: 카카오톡 알림에 "메시지 미리보기 표시"가 꺼져 있으면 내용을 읽을 수 없습니다. 그룹/오픈채팅
  발신자 이름 파싱은 "이름: 내용" 형식에 대한 추정입니다. 답장 전송은 카카오톡 UI 자동화라 앱 업데이트로
  깨질 수 있습니다.
- **메뉴 2**: YouTube Data API 무료 쿼터를 초과하면 그날은 새로고침이 실패합니다.
- **메뉴 3**: 구글 뉴스 RSS가 커버하지 않는 소규모 매체 기사는 누락될 수 있습니다. AI 요약은 원문 의미를
  바꿀 수 있어 완전히 정확하다고 보장하지 않습니다.
- **메뉴 4**: 게시물별 실제 링크를 얻을 수 없어 프로필 링크로 대체됩니다. 세 앱의 UI가 각각 다르고 자주
  바뀌므로 유지보수 부담이 크고, 계정 정지 위험이 있습니다.
- **메뉴 5**: 완전 자동이 아니라 알림을 탭해야 갱신됩니다. 화면 텍스트 파싱이 정확한 수입/지출 분류를
  보장하지 않으며, 확인이 필요한 값은 AI 요약에서 "확인 필요"로 표시됩니다.
