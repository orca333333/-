# ChatBridge (스마트폰 내역 통합 앱)

스마트폰의 여러 내역을 하나의 앱에서 확인/응답하는 것을 목표로 하는 안드로이드 앱입니다.
현재는 **메뉴 1: 카카오톡** 기능만 구현되어 있습니다. 메뉴 2, 3, 4는 추후 요청에 따라 추가됩니다.

## 메뉴 1: 카카오톡

- 카카오톡 알림 중 **내가 요청(선택)한 사람/채팅방(오픈채팅 포함)만** 앱 안에서 확인할 수 있습니다.
- 선택하지 않은 채팅방은 이름만 "채팅방 선택" 화면에 자동으로 나타날 뿐, 메시지 내용은 저장되지 않습니다.
- 채팅방을 열어 답장을 입력하면, 앱이 카카오톡을 열어 해당 채팅방에 자동으로 입력 후 전송합니다.

## 왜 이렇게 만들었는가 (중요한 제약)

카카오는 **개인 대화(친구/오픈채팅)를 읽거나 대신 전송할 수 있는 공식 API를 제공하지 않습니다.**
그래서 이 앱은 다음 두 가지 안드로이드 시스템 기능만으로 동작합니다.

1. **알림 접근 권한 (`NotificationListenerService`)**: 카카오톡이 띄우는 알림(발신자/채팅방 이름, 메시지 미리보기)을 읽습니다.
2. **접근성 권한 (`AccessibilityService`)**: 답장을 보낼 때 카카오톡 앱을 열어 채팅방을 찾고, 입력창에 텍스트를 넣고, 전송 버튼을 눌러줍니다. 카카오톡 화면 구성이 바뀌면 이 자동화가 깨질 수 있습니다.

이 방식 때문에:

- **안드로이드 전용**입니다. iOS는 이런 방식의 알림 가로채기/자동 입력이 기술적으로 불가능합니다.
- 구글 플레이 정식 심사에서는 반려될 가능성이 높아 **APK 사이드로드(직접 설치) 전용**으로 설계했습니다.
- 채팅 데이터는 **기기 내부(Room/SQLite)에만 저장**되며 서버로 전송되지 않습니다.
- 채팅방은 카카오톡 API로 목록을 가져올 수 없어 **알림에 찍힌 이름으로만 식별**합니다. 오픈채팅방 이름이 바뀌면 새 채팅방으로 인식됩니다.

## 처음 사용 설정

1. 앱 설치 후, 카카오톡 화면 상단 배너의 안내를 따라 다음 두 권한을 켭니다.
   - **알림 접근 권한** (설정 > 앱 > 특별한 접근 > 알림 접근)
   - **손쉬운 사용(접근성) 권한** (설정 > 접근성 > ChatBridge)
2. 카카오톡에서 메시지가 한 번 이상 와야 상단 메뉴의 "채팅방 선택" 화면에 목록이 뜹니다.
3. 확인하고 싶은 사람/채팅방을 켜면(요청함), 그 이후부터 오는 메시지가 앱에 표시됩니다.

## 빌드 방법

Android Studio(최신 버전)에서 이 폴더를 열면 Gradle Wrapper가 자동 생성됩니다.
CLI로 빌드하려면 로컬에 Gradle이 설치되어 있어야 하며(`gradle wrapper` 최초 1회 실행 후):

```
./gradlew assembleDebug
```

- `minSdk` 26, `targetSdk` 34, Kotlin + Jetpack Compose + Room 사용.
- 별도 서버/외부 API 키가 필요 없습니다(완전 온디바이스).

## 프로젝트 구조

```
app/src/main/java/com/chatbridge/kakao/
  data/            Room 엔티티, DAO, Repository (로컬 저장)
  notification/    KakaoNotificationListenerService (메시지 읽기)
  accessibility/   KakaoReplyAccessibilityService (답장 자동 전송)
  ui/screens/      채팅 목록 / 채팅방 선택 / 채팅 상세(답장) 화면
  MainActivity.kt  하단 메뉴(1: 카카오톡, 2~4: 추후 추가 예정) + 네비게이션
```

## 알려진 한계

- 카카오톡 알림에 "메시지 미리보기 표시"가 꺼져 있으면 내용을 읽을 수 없습니다.
- 그룹/오픈채팅에서 발신자 이름 파싱은 카카오톡 알림 텍스트 형식("이름: 내용")에 대한 추정이며 100% 보장되지 않습니다.
- 답장 자동 전송은 카카오톡 UI를 흉내 내는 방식이라, 카카오톡 앱 업데이트로 화면 구조가 바뀌면 실패할 수 있습니다(전송 실패 시 채팅방에 "전송 실패"로 표시됨).
