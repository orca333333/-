# Mono — 초 미니멀 흑백 런처

내 폰에서만 쓰는 개인용 안드로이드 홈 런처입니다. Grok과 나눈 설계를 그대로 구현했습니다.

- **메인 화면**: 배경(흰색/검은색)과 가운데 작은 흑백 로고 하나만 있습니다. 텍스트, 아이콘, 시계, 위젯 전혀 없음.
- **메뉴**: 화면 아무 곳이나 탭하면 설치된 앱들이 아이콘 + 이름으로 작게 세로로 쭉 나열됩니다. 탭하면 바로 실행.
- **다크/라이트 전환**: 메뉴 화면 우측 상단의 작은 글자(`시스템`/`라이트`/`다크`)를 탭할 때마다 순서대로 전환됩니다.
  기기에만 저장되고, 서버로 전송되는 값은 없습니다.
- 뒤로가기(제스처/버튼)를 누르면 메뉴에서 메인 화면으로 돌아갑니다. 홈 버튼을 누르면 항상 메인 화면부터 다시 보입니다.

이 저장소의 `app` 모듈(ChatBridge)과는 완전히 별개의 독립 앱입니다. 같은 저장소에 함께 있을 뿐, 서로 코드/데이터를 공유하지 않습니다.

## 설치 전 알아둘 점

- **구글 플레이 심사용이 아닙니다.** 사이드로드(직접 설치) 전용으로 만들었습니다.
- 네트워크 권한을 요청하지 않습니다 — 완전히 오프라인으로 동작합니다.
- 개인정보를 수집·전송하지 않습니다. 유일하게 기기에 저장하는 값은 다크/라이트 설정 하나뿐입니다.

## 로고 교체하기

지금은 임시 플레이스홀더(얇은 원형 링)가 들어 있습니다. 실제로 쓰실 흑백 로고가 있다면
`launcher/src/main/res/drawable/ic_logo_bw.xml` 파일을 같은 파일명으로 교체하세요.

- 벡터(SVG → Android Vector Drawable)로 교체하거나
- PNG를 쓰려면 같은 이름(`ic_logo_bw.png`)으로 `drawable/` 폴더에 넣고 기존 `.xml` 파일은 삭제하면 됩니다.
- 로고는 단색 실루엣(알파가 있는 형태)일수록 좋습니다 — 앱이 다크/라이트에 맞춰 색을 자동으로 다시 입혀줍니다.

## 빌드 & 설치 방법

1. Android Studio에서 저장소 루트 폴더를 엽니다 (기존 `app` 모듈과 함께 자동으로 `launcher` 모듈도 인식됩니다).
2. 상단 실행 구성(run configuration)에서 모듈을 `app`이 아니라 `launcher`로 선택합니다.
3. USB로 연결한 본인 폰에 Run(▶) 하거나, CLI로 APK를 빌드합니다.

```
./gradlew :launcher:assembleDebug
```

- 결과 APK 경로: `launcher/build/outputs/apk/debug/launcher-debug.apk`
- 이 APK를 폰에 직접 설치하세요 (출처를 알 수 없는 앱 설치 허용 필요).

## 기본 런처로 설정하기

1. 설치 후 홈 버튼을 누르면 "다음을 통해 홈 화면 열기" 선택 창이 뜹니다 — **Mono**를 선택하고 "항상"을 누르면 기본 런처가 됩니다.
2. 나중에 되돌리려면: 설정 > 앱 > 기본 앱 > 홈 앱(Home app) 에서 원래 쓰던 런처로 다시 바꾸면 됩니다.
   (기존 런처 앱은 삭제되지 않으니 언제든 되돌릴 수 있습니다.)

## 알려진 한계 / 다음에 다듬을 수 있는 부분

- 로고는 플레이스홀더입니다 — 위 안내대로 실제 로고로 교체해야 합니다.
- 앱 목록에 폴더/즐겨찾기/검색은 없습니다(요청하신 "작은 세로 리스트"에 맞춘 최소 구성).
- 위젯은 지원하지 않습니다(요청하신 스펙에 없었습니다).
